# CloudStorage Web Frontend

A responsive web application for CloudStorage matching the features of the native Android client.

## Features

- 🏠 **Home Dashboard**: Quick access to file categories (Images, Documents, Videos, Audio)
- 📊 **Storage Meter**: Visual breakdown of used and available storage
- 📤 **Drag & Drop Upload**: Upload multiple files with real-time feedback
- 🔍 **Real-time Search & Filter**: Search files by name and category
- ⭐ **Starred & Shared**: Easy organization for favorites and shared files
- 🗑️ **Recycle Bin**: Recover deleted items or delete permanently
- 💳 **Storage Upgrade Plans**: Interactive tier selection modal

## How to Run

You can open `index.html` directly in any web browser, or serve it locally using any static web server:

```bash
# Option 1: Double-click index.html or open via browser

# Option 2: Using Python (if installed)
python -m http.server 3000

# Option 3: Using npx serve (if Node.js is installed)
npx serve .
```
